How to Use ImageSaw

  1. Select image to be converted: Select the image you wish to convert in the Source image section
  2. Configure conversion settings: Configure the conversion as desired by tweaking the Conversion settings. For more info on what each option does, hover over them.
  3. Saving the converted text block: Either copy the text block from the Conversion Result box if planning to use it immediately, or click the "Download text block" button to download the result as a .txt file for later use.
  4. Using the converted text block Ingame: In the Gunsaw level editor, place down an Info Board / Sign
  5. Configuring Info Board / Sign: Set the Info Board's / Sign's scale to the recommended Estimated minimum sign size (If you changed the Size multiplier and / or Line height settings, this will be inaccurate! You will need to manually figure out the scale.)
  6. Pasting the converted image in: In the text field for the Info Board / Sign, paste your text block. Keep in mind that for longer text blocks (Above 100k Characters) you may experience a frame drop or lower FPS in the editor. Try to generate your initial conversion with this in mind.

Warning: Changing Size Multiplier or Line Height from their defaults may distort the image!
