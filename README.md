# ImageSaw
A tool used to convert images into ASCII art usable in the Info Boxes available in the Gunsaw Level Editor.

Relies on Python and Pillow. For now, not publicly released.

Notice: Increasing Size will vertically mirror the image. This is a limitation from the way Info Boxes render text in Gunsaw, as such you may need to vertically mirror your image before conversion.
